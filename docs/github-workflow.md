# Git / GitHub Workflow

- Conventional commits: `feat:`, `fix:`, `refactor:`, `test:`, `docs:`.
- One meaningful change per commit — no giant "final scanner" commits.
- Tests must pass locally before push.
- Every completed phase ends with a checkpoint summary (goal, implemented, files
  changed, tests, known limitations, commit hash, next phase) recorded in the phase's
  chat response and reflected in `CHANGELOG.md`.
